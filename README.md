# 小红书 & 抖音 去水印 + AI改写工具

一个功能强大的Web工具，支持小红书和抖音内容的去水印下载和AI智能文案改写。

## 🎯 功能特点

### 1. 去水印下载 (`media-downloader.html`)
- ✅ 支持小红书图文/视频下载
- ✅ 支持抖音视频下载
- ✅ 无水印原画质保存
- ✅ 批量图片下载
- ✅ 自动识别平台

### 2. AI文案改写 (`ai-rewrite.html`)
- ✅ 智能平台适配（小红书/抖音）
- ✅ 自动字数控制
  - 小红书：标题20字，正文1000字
  - 抖音：标题30字，正文2000字
- ✅ 多种改写风格
  - 自然流畅
  - 专业正式
  - 轻松活泼
  - 情感丰富
- ✅ 智能添加表情符号
- ✅ 自动生成话题标签
- ✅ 实时字数统计
- ✅ 一键复制结果

## 🚀 快速开始

### 方式一：直接使用
1. 下载所有文件到本地
2. 用浏览器打开 `media-downloader.html` 或 `ai-rewrite.html`
3. 开始使用

### 方式二：本地服务器
```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js
npx http-server

# 然后访问 http://localhost:8000
```

## 📖 使用说明

### 去水印功能

1. **打开工具**
   - 访问 `media-downloader.html`

2. **设置API密钥**（首次使用）
   - 点击右上角 ⚙️ 设置按钮
   - 输入API密钥：`puM4bNPd7nBIFcRXBUgvfutGzE`
   - 点击保存

3. **下载内容**
   - 在小红书/抖音APP中复制分享链接
   - 粘贴到输入框
   - 点击"解析下载"
   - 等待解析完成
   - 点击下载按钮保存

### AI改写功能

1. **选择平台**
   - 访问 `ai-rewrite.html`
   - 选择目标平台（小红书或抖音）

2. **输入原文**
   - 输入原始标题
   - 输入原始正文
   - 查看实时字数统计

3. **调整设置**
   - 选择改写风格
   - 设置创新程度
   - 选择是否添加表情和标签

4. **生成改写**
   - 点击"AI智能改写"
   - 等待AI生成结果
   - 查看改写后的内容
   - 点击"复制全部"使用

5. **重新生成**
   - 如果不满意，点击"重新生成"
   - AI会生成新的版本
